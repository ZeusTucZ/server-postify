# server-postify

> **This repository is not a separate project.** It holds only a minimal
> FastAPI "Hello World" starter (`main.py`). The real Postify backend lives
> in [ZeusTucZ/postify](https://github.com/ZeusTucZ/postify), under
> `server-postify/`, together with the React frontend in `ui-postify/`.

Postify is a social posting app — posts with text and images, likes and
comments. See the [Postify README](https://github.com/ZeusTucZ/postify) for
what it does and how to run it.
